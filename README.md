# Numerology Chart

A single-page name value calculator based on the Chaldean numerology letter chart.

Open `Numerology_Chart_v3.html` in any browser, type a name, and press Enter or click
Calculate. The page sums the value of each letter and shows the total.

The same chart is rendered at the top of the page for reference.

## Notes

- No build step, no dependencies — plain HTML, CSS, and JavaScript.
- Characters outside A–Z (spaces, digits, punctuation) contribute nothing to the sum.
